# Sistem Informasi Inventaris Barang 

## Instalasi
1. Salin folder yang sudah diextract ini ke `htdocs` (XAMPP) atau web root yang kalian gunakan
2. Impor `database.sql` ke Php My Admin.
3. Kredensial di `config/koneksi.php` disesuikan dengan konfigurasi kalian bila perlu.
4. Login: `admin` / `admin123`.

Persyaratan: PHP 7.4+ dengan ekstensi mysqli, MySQL/MariaDB.
